# Triage — what to pursue, what to shelve

The community feed is mostly noise. Out of ~130 scraped strategies only a handful
run on standard indicators; the rest lean on the author's own logic (market
structure, fair-value gaps, bespoke scores). This doc is the rule for deciding
where to spend effort.

## The funnel

```
scrape N scripts
  → static analyse
  → auto-assemble the ~5% that need only standard indicators
  → backtest + parameter sweep those            ← where "does this idea work" is answered
  → for the rest: triage (below)
       recurring primitive?  → build it once, it unlocks many
       one-off custom logic? → shelve (register, never re-analysed)
  → re-crawl periodically; the register means dead ends aren't re-worked
```

## Deciding on a non-assembling strategy

**Build the primitive** when the same missing piece blocks *many* scripts. The
`missing identifiers` and `unknown ta.*` tallies from `yarn assemble --all` /
`yarn reanalyze` are the evidence. If a fair-value-gap detector unlocks 25
scripts, build it. If a bespoke formula blocks 1, don't.
This is an **engineering-ROI** call — it has nothing to do with predicting edge.

**Shelve it** (add a `skip` + `category` entry to `strategies/curation.json`):

| category | meaning |
|---|---|
| `not-a-strategy` | dashboard, screener, cycle/analysis tool — no mechanical entry |
| `too-custom` | a real strategy, but its logic is a one-off no other script shares; wiring it up is a poor trade |
| `no-edge` | parameter sweep covered the whole space and nothing was profitable (still only "no edge on this market / timeframe / window") |
| `duplicate` | same script under another name |

A shelved script stays recorded in `curation.json` (committed) and is never
regenerated by `yarn reanalyze`. Over many crawls the register becomes a map of
the feed — how much is noise, which primitives keep recurring.

## What is NOT grounds to shelve

- **"Its family backtested poorly."** A slight parameter or filter change can turn
  a losing configuration into a good one. Judge a strategy by a *parameter sweep*
  over its whole space, not by its author's defaults, and not by other scripts
  that share its broad idea.
- **"It loses at default settings"** — before it has been swept.
- **Analyser defects** (truncated conditions, missed signals) — those are bugs to
  fix, not strategies to shelve.
